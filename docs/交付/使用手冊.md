# ELK 服務健康診斷使用手冊

本工具只讀取使用者指定的 Elasticsearch／Kibana／Logstash API，不執行修復。

## 先選擇一條路線

| 路線 | 誰在使用者環境操作 | 使用情境 | 操作手冊 |
|---|---|---|---|
| **Route A：採集資料後交付分析（主要路線）** | 使用者只執行 `collect.sh`，產生採集包壓縮檔 | 使用者環境不允許執行未知執行檔，或資料必須帶回指定環境分析 | [Route A 採集操作手冊](./路線A-採集操作手冊.md) |
| **Route B：Live 直連** | 獲准的分析機執行 `elk-diagnostics`，直連 ES 產生報告 | 分析機可執行交付執行檔，且可連線 ES | [Route B 直連操作手冊](./路線B-直連操作手冊.md) |

**每次只選一條路線。** 不要將 Route A 與 Route B 的檔案、參數或指令混用。

## 共通安全原則

- 密碼由執行時互動輸入，不寫入指令、設定檔、shell history 或版控。
- 正式環境必須驗證 TLS 憑證；`--insecure` 僅限測試。
- 報告是唯讀診斷引導，不等於已確認根因或自動修復。

API 呼叫面與資料範圍請參閱交付包內的 [API 清單](./API清單.md)。
