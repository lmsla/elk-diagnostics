# 驗證狀態

最後更新：2026-07-31。`implemented` 只代表程式與自動化測試完成；`verified` 代表已在真機故障分支確認結果。

## 已完成

- ES 8.14.3／ES 9.0.0：Live 與 Bundle 基準線、39 個採集端點、52 項診斷結果。
- P00～P16：ES8 Bundle Route B 已完成；P05 為多因子條件式通過，P11 受 Basic License 限制。
- M00～M09：ES8 三節點 Live／Bundle 已完成；M08 partial Nodes API 正確回 `unknown`。
- ES-GAP-06 高可用結構、ES-GAP-08 index block：已由 ES8 真機驗證為 `verified`。
- HTTPS、自簽 CA、Basic Auth、Bundle 離線分析與 HTML 報告：已驗證。

## 尚未宣稱真機完成

- 真實 indexing pressure、thread pool rejection、queue backlog。
- 真實 JVM heap／CPU／circuit breaker 負載。
- 真實 CCR follower、ML job/datafeed、planned shutdown/voting exclusion 異常。
- ES9 多節點、跨主機與長時間穩定性。
- Bundle 的 `--redact`：目前可能含 index、node、host 與 mapping 欄位名稱。

## 判讀規則

- 單次快照不能取代時間序列；高 RAM、CPU、I/O 或 heap 單點值不得直接當根因。
- partial API response 必須是 `unknown`，不能用已回應節點推論全叢集正常。
- P／M 案例的造壓結果只代表測試配方成立，不代表該故障涵蓋所有生產變體。
