# 設定規格 — 連線與設定

**實作位置**：`config.yaml`（範例與載入）＋ `collector/client.go`（連線）。
這是工具**唯一必填**的輸入。除連線外，其餘皆有預設。

## 1. 設定來源與優先序

```
flag  >  環境變數  >  config.yaml  >  內建預設
```

- 任一來源提供完整連線資訊即可，三者擇一。
- 缺連線資訊時，工具報明確錯誤並結束（exit code 見 命令列規格 §3），不嘗試 localhost 猜測。

## 2. config.yaml schema

```yaml
cluster:
  hosts:                          # 必填，可多個（依序嘗試，故障轉移）
    - "https://es-1.example.com:9200"
    - "https://es-2.example.com:9200"
  auth:
    type: api_key                 # none | basic | api_key | bearer
    username: ""                  # type=basic 時用；密碼預設由終端安全詢問
    password: ""                  # 僅向下相容；正式環境不得將密碼寫入檔案
    api_key: ""                   # type=api_key 時用（id:key 的 base64，或明文 encoded）
    token: ""                     # type=bearer 時用
  tls:
    ca_cert: "/path/ca.crt"       # 自簽 CA（政府/金融常見）
    client_cert: "/path/tls.crt"  # mTLS 時用
    client_key: "/path/tls.key"   # mTLS 時用
    insecure_skip_verify: false   # 預設 false；設 true 時報告與 log 強制警告
  timeout_seconds: 10             # 單請求逾時，預設 10
  retries: 2                      # 失敗重試次數，預設 2
```

## 3. 環境變數對映

| 變數 | 對映 |
|---|---|
| `ELK_DIAGNOSTICS_HOSTS` | `cluster.hosts`（逗號分隔） |
| `ELK_DIAGNOSTICS_AUTH_TYPE` | `cluster.auth.type` |
| `ELK_DIAGNOSTICS_USERNAME` / `_PASSWORD` | basic |
| `ELK_DIAGNOSTICS_API_KEY` | api_key |
| `ELK_DIAGNOSTICS_TOKEN` | bearer |
| `ELK_DIAGNOSTICS_CA_CERT` | tls.ca_cert |

對應 flag：`--config`、`--host`（可重複）、`--username`、`--api-key`、`--ca-cert`、`--insecure`、`--timeout`。`--password` 僅為向下相容而保留，已棄用。

## 4. 連線行為（client.go）

1. 依序嘗試 `hosts`，第一個成功者為本次連線（故障轉移）。
2. 連線後立即 `GET /` 取 `version.number`，供版本偵測與 fallback 判斷（見 命令列規格 §4）。
3. 全部 host 連不上 → exit code 連線錯誤，不產出報告（或產出僅含錯誤的 meta）。

## 5. 安全（鐵律）

- **唯讀**：client 只允許 GET/HEAD；實作層應封死寫入方法，杜絕誤送。
- **不落 log**：username/password/api_key/token 不得寫入任何 log 或報告；報告中 host 可顯示，認證資訊一律遮蔽。
- **密碼輸入**：互動式 Basic Auth 缺少密碼時由 binary 關閉終端回顯後詢問。非互動式執行才允許秘密管理系統注入 `ELK_DIAGNOSTICS_PASSWORD`；正式環境不得把密碼放入命令列或設定檔。
- `insecure_skip_verify: true` 時，報告頁首與 log 強制顯示安全警告。

## 6. 邊界

- MVP：一次執行對**單一叢集**（hosts 為同叢集多節點，非多叢集）。多叢集 profile 列為未來增強。
- 不提供任何寫入型設定（無「自動修復」開關）。

`tested_versions`: 與設定無關，不需標。
