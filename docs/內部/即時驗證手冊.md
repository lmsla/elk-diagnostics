# 即時連線（Live）驗證手冊

只驗證 binary 直接連 ES 的路線。前置環境依 [`共通準備.md`](./共通準備.md)；案例說明依 [`案例矩陣.md`](./案例矩陣.md)。

## 1. 設定 Live 連線

```bash
export ELK_DIAGNOSTICS_HOSTS="$ES_URL"
export ELK_DIAGNOSTICS_AUTH_TYPE=basic
export ELK_DIAGNOSTICS_USERNAME="$ES_USER"
export ELK_DIAGNOSTICS_CA_CERT="$CA_CERT"
export TOOL_BIN="$PWD/elk-diagnostics"
```

執行 binary 時會互動詢問密碼且不回顯；不要把真實密碼寫進命令列或 shell history。

## 2. 單案流程

以下以 P01 為例：

```bash
fault P01 trigger
fault P01 verify

mkdir -p "$EVIDENCE_ROOT/P01-fault"
"$TOOL_BIN" check --output html \
  --output-file "$EVIDENCE_ROOT/P01-fault/live-report.html"

fault P01 restore
fault baseline verify
```

故障未復原前可用同一 binary 產生 text／JSON；每次只執行一案。若中斷，先 restore 再繼續。

## 3. 結束

```bash
unset ELK_DIAGNOSTICS_HOSTS ELK_DIAGNOSTICS_AUTH_TYPE
unset ELK_DIAGNOSTICS_USERNAME ELK_DIAGNOSTICS_CA_CERT TOOL_BIN
```

Live 報告是當下快照；若要比較完全相同資料，改用採集包路線。
