# 實作進度

目前版本：`0.0.4-mvp`。本頁只記錄目前交付狀態；歷史討論與逐案證據不放在這裡。

## 已實作

- 唯讀 ES API collector、`_health_report` 優先與 raw API 加深。
- Live／採集包共用 analyzer；`check --from-bundle` 完整離線分析。
- JSON、HTML、text 報告；狀態分為 pass／warning／critical／skipped／unknown。
- ES 8.4+ 健康檢查、節點 OS／process／filesystem／JVM 快照與 partial coverage 判定。
- HTTPS／Basic Auth／CA、config.yaml、環境變數與 flags 設定來源。
- `collect.sh` 與 API 清單由端點表產生；`make dist` 產出 binary、採集腳本、API 清單與 SBOM。

## 正確性邊界

- 實作完成不等於異常分支已真機驗證；狀態以 [`驗證狀態.md`](./驗證狀態.md) 為準。
- OS 資訊只限 ES API 可見的節點快照，不是 SSH 主機健檢。
- 需要時間序列、外部叢集或真實負載的項目，不以單次採集包宣稱完成。
