# 驗證案例矩陣

案例只在內部測試叢集執行。P 系列限單節點；M 系列需至少三節點。

## P 系列（單節點）

| 案例 | 模擬情境 | 主要結果 |
|---|---|---|
| P01 | 叢集 allocation 封鎖 | cluster health critical、allocation blocked |
| P02 | index allocation 封鎖 | cluster health critical、index block |
| P03 | replica 無法放置 | yellow、same_shard |
| P04 | shards-per-node 超限 | red、shards limit |
| P05 | cluster shard 容量超限 | shards capacity critical |
| P06 | disk watermark | disk critical |
| P07 | ILM stopped | ILM critical |
| P08 | ILM ERROR step | ILM critical／`ilm-stuck` |
| P09 | mapping 欄位膨脹 | mapping explosion critical |
| P10 | search slow log 開啟 | slow log 設定正確 |
| P11 | Watcher stopped | watcher warning（Basic License 可能受限） |
| P12 | Transform failed | transforms critical |
| P13 | legacy monitoring 設定 | monitoring／deprecation 結果 |
| P14 | remote cluster 斷線 | remote clusters warning |
| P15 | ingest pipeline 失敗 | ingest errors warning |
| P16 | index write block | index read/write block critical |

## M 系列（多節點）

| 案例 | 模擬情境 | 主要結果 |
|---|---|---|
| M00 | 3 master、3 data、3 zone、hot/warm 基準線 | allocation awareness pass |
| M01 | awareness attribute 缺失 | allocation awareness warning |
| M02 | ILM hot→warm 遷移停留 | ILM tier migration warning |
| M03 | 相同角色 heap 設定漂移 | node runtime warning |
| M04 | master-only 磁碟離群 | hot spotting warning |
| M05 | data-hot/content 磁碟離群 | hot spotting warning |
| M06 | allocation 暫停造成 undesired shards | unbalanced warning |
| M07 | master-eligible 節點為偶數 | master stability warning |
| M08 | Nodes API 部分回應 | node API coverage unknown |
| M09 | 業務 index 為 0 replica | replica resilience warning |

M07 是結構性風險，不等於已重現選舉抖動；M08 的 `unknown` 是預期的保守結果。
